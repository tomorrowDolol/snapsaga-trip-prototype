CONCEPT

产品定位为什么做、给谁用

把 gpt-image-2 的「理解 + 重绘」能力装进口袋相机：真实照片是底座，AI 是放大器。它不替你拍照，而是先教你怎么拍，再帮你把拍到的变成作品、漫画和纪念品。

目标用户
  • 结伴出游的年轻人：爱分享、想发点不一样的，但不会修图、面对镜头紧张
  • 亲子家庭：记录成长，漫画是孩子故事的自然载体
  • 摄影小白：不懂参数，需要的是引导而不是器材
三个使用时刻
  • 拍摄中（0–3 秒）：引导必须实时 → 全部端侧实现
  • 拍完（10–30 秒）：即时反馈——拍立得效果、一键主题预览
  • 归途 / 夜里（3–10 分钟）：批量创作——连续漫画、照片墙
设计原则
  • 引导在前，生成在后：AI 先帮你拍好，再帮你修好
  • 真实为底：重绘永远围绕用户照片，不虚构旅行
  • 即时愉悦，重度异步：轻效果本地秒出，重生成排队后台
  • 弱网韧性：山区海边也能用——引导与拍立得完全离线

Provider 抽象层（重要）

gpt-image-2 的可达性与时延存在区域差异：所有生图调用经统一抽象接口，预置备用路由与排队降级策略（弱网时自动降为「先拍后批量生成」）。业务代码只依赖接口，不绑定单一服务商。

DESIGN SYSTEM

视觉与设计系统胶片旅行的温度感

关键词：胶片暖白 × 深青墨色 × 落日橙。拍立得白框作为贯穿全 App 的视觉母题—— loading 叫「显影」，进度条是胶片齿纹，快门有黑框闪动。

字体与语气
  • 标题：大号无衬线 + 少量手写体点缀（日记感）
  • 文案语气：同行的朋友，不是工具说明书——「黄金时刻还剩 42 分钟，抓紧！」
动效原则
  • 快门：黑框闪动 + 轻微 haptic，模拟机械快门
  • 显影：10s 渐现，等待本身是产品体验的一部分
  • 生成等待：胶片齿纹进度条 + 「暗房里正在冲洗…」

RISKS

关键风险与对策提前把丑话说清楚

💸

生图成本失控

高频功能（拍立得/引导）坚持零生图成本；重生成两段式（512 预览→1024 成品）+ 每月配额 + 订阅。成本模型先算后上线。

🎭

漫画角色不一致（最大技术风险）

参考图链 + 固定种子 + 人脸锁定三管齐下；产品上以「每格一次免费重生成」管理预期，把技术短板变成可接受的小互动。

📶

山区海边弱网

端侧功能全覆盖离线；生成任务本地队列持久化，回到网络自动续跑并推送通知——创作不因断网中断。

⚖️

合规与内容安全

AI 生成内容按法规要求显式标识 + 元数据声明；人像重绘需被摄者同意提示；输入输出双审核；未成年人模式。

🔌

模型可达性与时延

Provider 抽象层预置备用路由；高峰排队 + 弱网降级为「先拍后批量」，保住拍摄主链路体验。
